Continue P11–P16 on the existing draft branch. M3 timing uses frozen images from
`c1f4baf`; changes below do not relabel that qualification or close its economics.

## P11: shared tail-clause construction

The existing `src/source/tail_clauses.zig` already consumes admitted activation
records. Its sole production caller is `src/source/activation_lower.zig`.
The selected ordinary boundary moves that implementation to
`src/data/tail_clauses.zig`, preserving the existing source normalization call.
The source implementation is deleted, with no migration adapter or second
handler compiler. This is a dependency of the named P11/P31 closed-link delivery,
not an authoring-uniformity prerequisite.

The next semantic extension must prove that an administrative copy/jump suffix
returns exactly the answer produced by a deep linear resumption. Preserve the
existing mode, totality, token-use, ownership and nominal guards. Construction
may track aliases forward; certification must independently trace the returned
slot backward through moves and simultaneous assignments. An arithmetic or
effectful suffix, a cycle, a retained token, or a different returned value must
not be treated as an identity continuation. Original and candidate admission,
exact record correspondence and final P01 remain required.

The source/structural normalization keeps its existing adjacent-return matcher.
The extended case belongs to semantic closed compilation and final linking.
Deciding evidence includes a real emitted administrative-tail rewrite, a
source-free closed-link witness, independent mutations and unchanged general/
shallow fallbacks, followed by native/WASM behavior and cost qualification.
The shared-module move alone is not a delivered optimizer capability. P11's
separate dynamic-installation evidence obligation and P12–P16 remain open.

## Capability forwarding

The second P11 construction uses actual value identity at private worker calls.
Every caller must supply the same slot in two capability argument positions;
both formals must remain unwritten, both must be used, and the replaced formal's
uses must be covered capability/evidence operands. Exact schema identity and
copy/drop permission are required. Host, constructor, handler and resource
entries retain unknown inputs. Descriptor equality alone never selects a rewrite.

`evidence_forwarding.zig` substitutes the proved duplicate capability reads,
checks actual record changes against a fresh raw caller/use census, then invokes
the existing checked dead-argument pass. Both operation sites remain: the initial
positive removes one parameter and one call argument while preserving two
performs. Admissible unchanged-candidate mutation, zero-work rollback, overwritten
formals and distinct argument-slot cases are covered by 20 passing focused tests.
The shared semantic pipeline invokes it after tail-clause specialization.

This fragment still needs source-free/native/WASM witnesses, allocation coverage
and a concrete distinct-installation fixture. The distinct-slot unit case is a
conservative alias rejection, not proof that its runtime installations differ.
